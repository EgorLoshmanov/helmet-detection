# Датасет FORTNITEBALLS

## Исходный набор

- Название: Safety Helmet Detection / Hard Hat Workers.
- Публикация: `andrewmvd/hard-hat-detection`, Kaggle.
- Версия архива: Kaggle dataset version 1.
- Получено: 19 сентября 2026 года.
- Объём: 5000 изображений и 5000 аннотаций Pascal VOC.
- Разрешение изображений: 416 × 416.
- Исходные классы: `helmet`, `head`, `person`.
- Лицензия на странице источника: CC0 1.0 / Public Domain.
- URL: https://www.kaggle.com/datasets/andrewmvd/hard-hat-detection
- SHA-256 архива: `aa5c80a85f9f4bd3b27e44256f8e36f9a32c53ee423132fa6cd5ea603781be62`.

Источник просит указывать авторов набора даже при свободной лицензии. Рекомендуемая ссылка приведена на странице Kaggle и относится к Hard Hat Dataset от MakeML.

## Преобразование классов

| Исходный класс | Класс проекта | ID | Решение |
|---|---|---:|---|
| `helmet` | `helmet` | 0 | сохранить |
| `head` | `no_helmet` | 1 | переименовать |
| `person` | — | — | игнорировать |

`person` нельзя преобразовывать в `no_helmet`: бокс человека не сообщает, надета ли на нём каска. Изображения, в которых есть только `person`, но нет ни `helmet`, ни `head`, исключаются, чтобы не создавать ложные фоновые примеры с неразмеченными головами.

## Воспроизводимая подготовка

Из корня проекта:

```bash
python3 scripts/prepare_dataset.py
```

Скрипт:

1. проверяет PNG-сигнатуру, CRC всех PNG-чанков и размеры;
2. проверяет соответствие XML и изображения;
3. проверяет и при необходимости ограничивает bounding box границами кадра;
4. удаляет некорректные боксы и точные дубликаты изображений;
5. преобразует Pascal VOC в YOLO;
6. выполняет детерминированное стратифицированное разделение 80/10/10 с seed `20260919`;
7. создаёт отчёт, манифест и визуальное HTML-превью.

Выходной набор создаётся в `dataset/processed/helmet_yolo_v1`. Изображения добавляются жёсткими ссылками, поэтому при поддержке файловой системой не занимают второй полный объём.

## Ограничения

- Источник не содержит идентификаторов видеороликов или съёмочных сессий. Точные дубликаты удаляются до разделения, но автоматически доказать отсутствие близких кадров одной сцены нельзя.
- Собственные кадры с целевой камеры пока не добавлены, поскольку камера стенда физически не подключена или не определяется.
- Кадры с целевой камеры следует группировать по записи и целиком назначать только в один из `train`, `val` или `test`.
- Перед обучением требуется вручную просмотреть HTML-превью и отдельно проверить сложные случаи.
